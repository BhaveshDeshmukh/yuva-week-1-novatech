# NovaTech - Responsive Web Design

## Project Overview

NovaTech is a modern agency landing page designed to present digital
services, showcase illustrative project concepts, and help visitors
connect with the business.

This project focuses on responsive web design, clean layouts,
consistent styling, and an improved browsing experience across
different screen sizes.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Media Queries
- Responsive Typography

## Features

- Modern dark-themed user interface
- Responsive navigation
- Hero section with dashboard illustration
- Services section with service cards
- Selected Concepts section showcasing illustrative projects
- About section
- Four-step How We Work section
- Contact section and footer
- Responsive layouts for desktop, tablet, and mobile screens

## Responsive Design

The website uses CSS Grid, Flexbox, flexible widths, and media queries
to adapt its layout to different screen sizes.

Responsive styling adjusts the navigation, typography, hero section,
cards, spacing, and buttons for smaller screens.

## Testing

The website should be tested at the following viewport widths:

- 1440px - Desktop
- 1024px - Laptop
- 768px - Tablet
- 390px - Mobile
- 320px - Small mobile

Testing includes checking layout alignment, text readability,
navigation, buttons, card layouts, and horizontal overflow.
