# YUVA Internship — Week 1 Report

## Project Title
NovaTech — Digital Agency Landing Page

## 1. Objective
The objective of this task was to develop a static website using HTML and CSS. The project focuses on organizing webpage content, applying styling, and presenting a professional digital agency interface.

## 2. Technologies Used
- HTML5
- CSS3
- Media queries
- Google Fonts

## 3. Implementation
The website was developed using HTML for its structure and CSS for its visual presentation. The page contains a navigation bar, hero section, services, portfolio concepts, about section, development process, contact section, and footer.

CSS was used to establish the dark visual theme, typography, spacing, cards, buttons, and layout. Media queries were included to adapt the layout to different screen widths.

## 4. Key Features
- Structured website sections
- Consistent dark theme with violet accents
- Service and portfolio cards
- Navigation links to page sections
- Responsive styling
- Contact call-to-action
- Project documentation

## 5. Testing
The website was opened in a web browser and its main sections were reviewed. Responsive layouts should also be checked at desktop, tablet, and mobile viewport sizes before final submission.

## 6. Learning Outcomes
- Practiced structuring content with HTML5.
- Applied CSS styling and layout techniques.
- Organized a webpage into reusable visual sections.
- Learned the importance of responsive design and documentation.

## 7. Conclusion
The Week 1 task produced a static digital agency landing page using HTML and CSS. The project establishes the foundation for further improvements in responsive design, JavaScript interactivity, accessibility, and performance during subsequent internship tasks.
