# NovaTech — Digital Agency Landing Page

## Project Overview
NovaTech is a responsive digital agency landing page developed as part of the YUVA internship Week 1 task. The project demonstrates how HTML and CSS can be used to transform a design concept into a structured website.

## Objectives
- Build a static webpage using HTML5 and CSS3.
- Create a clean, professional user interface.
- Organize content into clear website sections.
- Apply responsive styling for different screen sizes.
- Use semantic HTML elements and reusable CSS styles.

## Features
- Navigation bar and hero section
- Services section
- Illustrative project portfolio
- About section
- Development process section
- Contact call-to-action
- Dark theme with violet accents
- Responsive CSS layouts

## Technologies Used
- HTML5
- CSS3
- Media queries
- Google Fonts

## Project Structure
- `index.html` — Website structure and content
- `style.css` — Website styling and responsive layouts
- `README.md` — Project documentation
- `Week_1_Report.md` — Internship task report

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Note
The portfolio cards contain illustrative project concepts. They are included to demonstrate interface design and do not represent completed client projects.
